## 2. 유심 결정

- **다이소 주황색 SKT망 「LTE 100분/1GB, 월 3,300원」** (유심 ₩5,000)
  - 데이터 사용량: ping JSON 1~2KB, 10분 주기라도 월 10~20MB → 1GB 충분
  - 비교: KT망 1GB 4,400원 / LGU+ 1GB 9,900원 이상 / 흰색 해외로밍 카드는 사용 불가
  - SKT: 최저가 + 이 보드에서 잡히는 밴드 4개(1,3,5,7), B5(850MHz) 저주파가 하천·둑 아래에 유리
- 개통: 카드 QR(브랜드 「고고비」) → 요금제 선택 → 본인인증 → 유심 일련번호 → **기기 IMEI 칸에 보드 IMEI**(`AT+GSN`) → APN 보통 `lte.sktelecom.com`(확인 필요)
- 명의: 시험 1장은 본인 명의 OK. **30회선은 법인 명의 가능 여부 고객센터 확인**(알뜰폰 1인 회선 제한, 지원금 「통신 유심비」 정산)
- 30대 × 12개월 ≈ 119만 원 + 유심 15만 원 (제안서 V3 「기술·공개 550만」 내)
- 순서: 1장 먼저 개통 → `/api/observations/drift/ping` 수신 확인 → 나머지 구매

### 수납함 사용 시 필수 조치
1. **2차 방수**: 부품을 지퍼백/진공팩 + 실리카겔에 밀봉, 이음새·**경첩 틈**을 투명 방수테이프 또는 자기융착 테이프로 감기
2. 바닥 가운데 점·모서리 원형 자국이 **구멍이 아닌지 확인**
3. 재질 PS 추정 → 충격에 금 가기 쉬움 → 둘레 아래쪽에 **EVA 폼 범퍼**(안테나 높이보다 아래)
4. **무게추**는 바닥에, 패널 면만 물 위로 나오게. 너무 높이 뜨면 바람에 밀려 궤적 왜곡
5. 배치: 패널은 뚜껑 바로 아래, GPS 패치는 패널 옆(하늘 방향), **LTE 띠 안테나는 긴 옆면 위쪽(물 위)**, 패널 뒤·18650에서 1~2cm 이상 이격
